模块功能

这里按用户可见面板和代码模块说明当前功能边界。面板负责交互，module 负责把面板连接到控制器、设备和 metadata。

用户可见面板

面板功能关键说明
Device Manager设备地址编辑、连接/断开、function assignment、硬件状态显示。启动时自动浮动打开；扫描或 approach 运行/暂停时会锁定。
Scan Parameters设置扫描中心、宽高、像素、行数、速度、采样/settle/rest、channel、模式。X/Y 单位为 V，并显示估算全图扫描时间。
ControlsScan Up/Down、Pause、Resume、Stop、Save GSF、Auto Save、连续/指定次数扫描。支持单次、连续上下扫、固定次数交替扫描。
Channel Images多通道图像显示、trace/retrace 选择、flattening、colormap、自动/手动 color range、ROI。默认 4 个 image view，锁相模式默认 A/B 启用。
Line Plot显示最新一行扫描线。长时间运行只保留最新线，降低内存压力。
Stage MapXYZ 位移台 jog、绝对移动、home、Z home、路径显示。默认 coarse_stage 为 Attocube；XY/Z step 默认 1 um。
Lock-in AmplifierLock-in apply/read、Channel 1/2 设置、Scan Routing A-D。Zurich HF2LI 支持 ch1/ch2；SRS 设备通常只有 ch1。
Approach通用条件式进针：小步 Z 运动、读信号、满足条件后停止。支持 mock 和真实 coarse_stage.z，真实信号来自已连接 lock-in。
State扫描状态、当前 line/pixel/pass 进度。逐点硬件扫描时用于判断是否卡在某个阶段。
Parameter Tree显示当前 metadata 树。不在每行刷新，只在关键事件刷新。
Command Log显示操作日志。保留最近 5000 个 text block。

UI Modules

模块职责
DeviceModule管理 Device Manager 面板、连接状态、硬件锁定和配置加载。
ScanModule从 GUI 读写 ScanConfig、启动扫描、处理扫描状态。
ScanSequenceModule处理单次、连续上下扫、指定次数扫描序列。
ChannelImagesModule创建/刷新图像视图、ROI、flattening、color scale、channel label。
LockInModuleLock-in panel 状态、apply/read、routing table、snapshot。
StageModuleStage Map 面板和 stage adapter/fallback 控制。
ApproachModuleApproach 面板、真实/模拟 actuator provider、lock-in signal provider。
StorageModule手动保存、Auto Save、GSF bundle 输出。
MetadataModulemetadata snapshot、参数树刷新、导出前补充状态。
WindowLayoutModule默认布局、浮动窗口、View 菜单和用户布局保存/加载。

Core Modules

模块职责
scan_config.pyScanConfig 数据结构和扫描参数。
scan_controller.py扫描状态机、line data、pause/resume/stop、参数树更新。
lockin_acquisition.py把 Scan Routing 变成逐点读数 callback。
stage_controller.pyStage fallback 和本地位置状态。
lockin_controller.pyLock-in 面板本地状态和 fallback readout。
approach_config.pyApproach 配置和 stop condition 判断。
approach_controller.pyApproach 状态机、定时步进、pause/resume/abort/retract。
parameter_tree.pymetadata 树构建。
scan_modes.py读取 scan mode 和 channel 定义。

当前暂缓模块

Spectroscopy 的 panel、controller 和 HDF5 数据格式已经有 MVP，但主界面暂时隐藏。原因是它与真实硬件之间的触发、bias sweep、逐点同步关系还没有完全确定。
