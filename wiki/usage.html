使用流程

推荐从最小动作开始验证：先连接设备，再读锁相，再小步移动 stage，再小图扫描，最后尝试 Approach。

1. 启动程序

conda run -n afm-gui python -m afm_gui.main

确认 Device Manager 自动弹出。若没有弹出，可从 View 菜单打开。

2. 连接硬件

  1. 在 Device Manager 中检查 multifield_scanner、attocube_xyz、zurich_HF2LI 的 Connection JSON。
  2. 根据当前实验室连接修改 COM 口、host、device id 或 VISA address。
  3. 点击 Apply Connection。
  4. 点击 Connect Assigned，或逐个选择设备后点击 Connect。

3. 验证 Lock-in

  1. 从 View 打开 Lock-in Amplifier。
  2. 选择 channel，设置 frequency、amplitude、phase、time constant 等。
  3. 点击 Apply 写入仪器。
  4. 点击 Read，确认 X/Y/R/Theta/Frequency 不再只是未连接时的 0。

4. 配置 Scan Routing

Lock-in panel 的 Scan Routing 使用 A、B、C、D 表示内部图像信号槽：

A -> zurich_HF2LI : ch1 : x
B -> zurich_HF2LI : ch1 : theta
C -> srs_sr830    : ch1 : r
D -> zurich_HF2LI : ch2 : frequency

点击 Apply 后，Channel Images 中会显示类似 A-zurich_HF2LI-x 的名称。

5. 验证 Stage Map

  1. 确认 coarse_stage 已连接，默认是 attocube_xyz。
  2. 先使用 1 um 或更小步长测试 +X/-X/+Y/-Y/+Z/-Z。
  3. 确认方向符合实际硬件坐标。
  4. 必要时使用 Move XY、Move Z 或 home 功能。

6. 设置扫描参数

  • 中心和宽高单位是 V，因为当前扫描器是开环电压控制。
  • 速度单位是 V/s。
  • 默认 lockin mode，默认 channel A/B 记录，默认显示 4 个 image view。
  • 全图扫描时间会根据 lines、width、linear、settle、sample、rest 自动估算。

7. 扫描

  • Scan Up 或 Scan Down：单次扫描。
  • Repeat mode 选择 Continuous Up/Down：连续上下交替扫描。
  • Repeat mode 选择 Count：按指定次数上下交替扫描。
  • Pause、Resume、Stop 管理当前扫描或序列。

8. 使用 Channel Images

  • 每个 image view 可以选择 channel 和 trace/retrace。
  • Flattening 支持 Raw、Line Mean、Plane，只影响显示，不改变保存的 raw data。
  • Color scale 支持自动范围和手动 min/max。
  • 左键拖拽可创建 ROI，右键菜单可把 ROI 加载到下一次扫描参数。

9. Approach

  1. 先用 mock.z 和 mock signal 验证按钮、阈值和状态变化。
  2. 真实进针时选择 coarse_stage.z。
  3. Signal device 选择已连接 lock-in，设置 channel 和 quantity。
  4. 设置 step、settle、condition、threshold、consecutive、max travel、max steps。
  5. 从非常保守的步长和 travel limit 开始，人工观察仪器响应。
当前 Approach 是通用条件控制器，不是已经验证完的 AFM/STM 自动进针 recipe。真实进针前必须确认 Z 方向、信号符号、阈值和硬件限位。

10. 保存数据

  • Save GSF 手动保存当前图像 bundle。
  • Auto Save 默认开启，默认目录是 ~/AFM_scans。
  • 暂停和完成扫描时会自动写 timestamped bundle。
