测试、备份与维护

当前项目已经启用 git 管理，并保留手动源码备份流程。每次接入硬件或修改扫描链路后，都建议跑完整测试。

测试命令

conda run -n afm-gui python -m unittest discover -s tests

如果要检查语法编译：

conda run -n afm-gui python -m compileall afm_gui tests

当前测试覆盖

  • 核心 scan/export 行为。
  • metadata tree 渲染。
  • GUI module wiring。
  • ROI 到 scan parameter 的写入。
  • Lock-in Scan Routing。
  • 连续/指定次数扫描序列。
  • Approach mock 和真实 adapter 路径。
  • runtime metadata updates。
  • Spectroscopy export。
  • Auto Save bundle。

手动备份规则

备份当前源码时应排除大型外部/生成目录：

  • .git/
  • backups/
  • AFM_scan_reverse/
  • autosave-scan/
  • Hardwares/

但 afm_gui/device/vendor/ 必须保留，因为 GUI 会从这些固定路径 import 厂商驱动副本。

维护优先级

  1. 真实硬件使用前，先用 Device Manager 和单面板读写验证。
  2. 扫描链路修改后，必须跑完整 unittest。
  3. Approach 真实 recipe 需要逐个模式验证，不能仅凭通用控制器直接无人值守运行。
  4. Spectroscopy 重新启用前，需要先定义真实硬件触发、bias sweep 和数据同步方式。
  5. 大图扫描前继续完善内存预算 warning 或 chunked on-disk recording。
