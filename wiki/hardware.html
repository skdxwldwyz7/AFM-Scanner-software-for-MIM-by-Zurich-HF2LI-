在 GUI 中连接硬件

  1. 启动 GUI，Device Manager 会自动弹出。
  2. 在 Configured Devices 表中选择设备。
  3. 双击或编辑 Connection JSON，例如端口、host、device id 或 VISA address。
  4. 点击 Apply Connection。
  5. 点击 Connect 连接当前设备，或点击 Connect Assigned 连接被 function 使用的设备。
  6. 到对应面板执行最小动作：Stage 小步移动、Lock-in Read、Scanner 小图扫描、Approach mock/小步测试。

添加新硬件的标准步骤

  1. 先在 notebook 或独立脚本中验证最小硬件闭环：import、connect、read status、安全小动作、close。
  2. 把厂商驱动复制到 afm_gui/device/vendor/<vendor>/，避免依赖临时路径。
  3. 在 afm_gui/device/adapters/ 新建 adapter，封装厂商 API。
  4. 在 afm_gui/device/registry.py 注册 driver 字符串。
  5. 在 afm_gui/config/devices.yaml 添加设备定义。
  6. 如果是功能设备，在 functions 中分配给对应 function。
  7. 添加 registry/adapter 单元测试，真实硬件测试保留为手动流程。

Approach 真实硬件规则

  • mock.z 和 mock signal 用于离线验证。
  • coarse_stage.z 必须要求 coarse_stage 已连接。
  • 真实信号源必须是已连接且支持 read_demod 的 lock-in。
  • 如果真实硬件缺失，Approach 进入 Failed，不会默默回退到 mock。
  • Approach 运行或暂停时，Device Manager 会被锁定。
新硬件先不要从 GUI 开始调。GUI 只能帮你统一连接和调用；端口、驱动版本、厂商服务、坐标方向和安全限位必须先在最小脚本中确认。
