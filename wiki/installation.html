安装与运行

当前开发环境名为 afm-gui。推荐使用 conda 管理 Python 环境，用 uv pip 安装项目，速度更快。

环境要求

项目要求
Python>= 3.12
主要 GUI 依赖PyQt6、pyqtgraph
仪器控制依赖QCoDeS、qcodes-contrib-drivers、pyserial、PyYAML
数据依赖numpy、scipy、pandas、h5py、matplotlib

新建环境

conda create -n afm-gui python=3.12
conda activate afm-gui
python -m pip install uv
uv pip install -e .

启动 GUI

conda run -n afm-gui python -m afm_gui.main

也可以在已激活环境中使用入口脚本：

afm-gui
afm-cli gui

CLI 常用命令

afm-cli modes
afm-cli channels --mode lockin
afm-cli devices
afm-cli stage --dx 10 --dy 0 --dz 0
afm-cli lockin --channel ch1 --output --frequency 1000 --amplitude 0.1
afm-cli preview-commands --mode lockin --direction up --pixels 128 --lines 128
afm-cli scan --mode lockin --direction up --pixels 128 --lines 128 --export-gsf ./scan_out

首次启动会看到什么

  • 主窗口使用 dock 布局，包含 Scan Parameters、Controls、Stage Map、Channel Images、Line Plot、State、Parameter Tree、Command Log 等面板。
  • Device Manager 会在启动时以浮动窗口打开，方便立即检查硬件连接状态。
  • Lock-in Amplifier 和 Approach 可以从 View 菜单打开。
  • Spectroscopy 功能目前保留在代码中，但暂时从主界面隐藏。

安装后快速检查

conda run -n afm-gui python -m unittest discover -s tests

当前版本最近一次完整检查为 55 个测试全部通过。

真实仪器连接前，先确认端口、VISA 地址、LabOne server、厂商驱动和 Python 包都在 afm-gui 环境内可用。
