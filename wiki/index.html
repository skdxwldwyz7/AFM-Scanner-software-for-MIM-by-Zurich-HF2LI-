AFM Scan Control Wiki

这个站点整理当前 GUI 原型的安装方式、硬件接入方法、软件架构、模块功能和日常使用流程。它是静态网页，可以直接打开，也可以以后发布为项目文档站。

当前软件定位

AFM Scan Control 是一个基于 PyQt6、pyqtgraph 和 QCoDeS 思路构建的 AFM 扫描控制 GUI。当前版本重点支持开环电压扫描、Lock-in 扫图路由、XYZ 位移台控制、Device Manager 硬件连接、通用 Approach 控制、GSF 导出和完整 metadata 保存。

默认工作模式

当前启用的扫描模式是 lockin，默认显示 4 个 image view，默认记录 A/B 两个信号。

硬件接入

通过 devices.yaml 定义设备，通过 Device Manager 编辑地址、连接设备、分配功能。

真实硬件路径

扫描器、粗定位台、锁相放大器和 Approach 均已接入 adapter 路径，未连接时保持 mock 或显式失败。

数据保存

图像以 GSF bundle 保存，metadata JSON 同步记录扫描参数、硬件快照、路由、stage 和 approach 状态。

推荐阅读顺序

  1. 第一次部署：先读 安装与运行。
  2. 连接仪器：读 添加与连接硬件。
  3. 理解代码：读 整体架构 和 模块功能。
  4. 上机测试：按 使用流程 从 Device Manager、Lock-in、Stage、Scan、Approach 逐步验证。
  5. 保存和回溯数据：读 数据与元数据。
